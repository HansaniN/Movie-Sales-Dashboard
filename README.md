# 🎬 Movie Sales Dashboard

An Excel dashboard analyzing Hollywood’s most profitable stories (2007–2011).  
Built from the Kaggle dataset: [Hollywood’s Most Profitable Stories](https://www.kaggle.com/datasets/brendan45774/hollywood-most-profitable-stories).

## 📊 Features
- **KPIs**:  
  - Total Movies (74)  
  - Total Worldwide Gross ($10.09 B)  
  - Average Profitability (4.74)  
  - Top Grossed Movie: *The Twilight Saga: New Moon*  
  - Top Profitable Movie: *Fireproof*  
  - Top Studio: Warner Bros.  
  - Top Genre: Comedy  

- **Visualizations**:  
  - Top 10 Movies per Worldwide Gross  
  - Top 10 Most Profitable Movies  
  - Top Genres per Worldwide Gross  
  - Box Office Trend over the Years  
  - Average Profitability by Genre  

## 📂 Files
- `MovieSalesDashboard.xlsx` → Interactive Excel dashboard with KPIs and charts  
- `HollywoodsMostProfitableStories.csv` → Source dataset (optional to include)

## 🚀 How to Use
1. Download `MovieSalesDashboard.xlsx`.  
2. Open in Excel (2016 or later recommended).  
3. Use slicers (Year, Genre, Studio, Rating Level) to filter results.  
4. Explore KPIs and charts for insights into Hollywood’s box office performance.

## 📝 Notes
- Values are expressed in **millions of USD** in PivotTables.  
- KPI cards convert totals into **billions** for readability.  
- Dashboard designed for clarity and recruiter‑friendly presentation.
